Welcome to the official GitHub for **FIRST Robotics Competition Team 247, Da Bears**.

## Onboarding

Follow these steps in order to get ready:

### 1. Core FRC Setup
* [WPILib Installation Guide](https://docs.wpilib.org/en/stable/docs/zero-to-robot/step-2/wpilib-setup.html) — The starting point (installs VS Code, Java, and GradleRIO).
* [Installing the FRC Game Tools](https://docs.wpilib.org/en/stable/docs/zero-to-robot/step-2/frc-game-tools.html) — Required for the Driver Station and RoboRIO imaging.

### 2. Vendor Libraries & Hardware Tools
* [CTRE Phoenix 6 Tuner](https://v6.docs.ctr-electronics.com/en/stable/docs/tuner/index.html) — Required for configuring, testing, and tuning our Kraken motors.
* [PhotonVision Documentation](https://docs.photonvision.org/en/latest/index.html) — Vision processing software setup.
* [PathPlanner](https://pathplanner.dev/home.html) — Application and WPILib vendor library for generating and following autonomous trajectories.

### 3. Reference Material
* [WPILib Java API Docs](https://github.wpilib.org/allwpilib/docs/release/java/) — Complete class and method reference.
* [Programming the Radio](https://docs.wpilib.org/en/stable/docs/zero-to-robot/step-3/radio-programming.html) — Tools for configuring the robot radio/network.
* [PhotonVision Pose Estimation](https://docs.photonvision.org/en/latest/docs/examples/poseest.html) — How we handle robot localization on the field.

## Mentors & Contributing

* **Questions?** Message the programming mentors via Slack.
* **Code Contributions:** Branch off `main`, test your changes (via simulation or on the RoboRIO), open a Pull Request against `main`.
